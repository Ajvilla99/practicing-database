# PASO A PASO

## 1. 🚀 Inicializar el Proyecto Node.js

Ingresar a la carpeta backend

```bash
cd ./backend
```

Una vez ubicado en el directorio backend, inicializa el proyecto de Node.js ejecutando el siguiente comando:

```bash
npm init -y
```

Este comando creará automáticamente un archivo package.json, el cual contiene la configuración básica del proyecto y permite gestionar las dependencias y scripts.

✅ ¿Qué hace la opción -y?
La opción -y (equivalente a --yes) acepta todas las configuraciones por defecto sin realizar preguntas interactivas, lo que agiliza el proceso de inicialización.

---

## 2. 📦 Instalación de dependencias

Para instalar las librerías necesarias, ejecuta el siguiente comando en la raíz del proyecto:

```
npm install pg express cors csv-parser
```
